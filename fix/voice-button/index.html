Grok Bot voice chat from the Action Button

Cursor's help doesn't document a way to start a Grok Bot voice call directly from the iPhone Action Button. A one-press voice call isn't documented. The closest working setup is: set the Action Button to open the Grok Bot app, open the Bot, then choose Start voice chat (the waveform button).

The closest path

A one-press voice call isn't documented. Cursor's voice-chat help does not mention the Action Button, and Apple's Action Button guide does not mention Grok Bot. Nothing on these pages is a URL scheme or a deep link into a call.

After the button is assigned, the path is three moves:

  1. Press and hold the Action Button set to open the Grok Bot app. That opens the app. It does not start the call.
  2. Open the Bot. In Cursor's words: open the chat with the Bot.
  3. Leave the message box empty and tap Start voice chat, the waveform button. Allow the microphone if the phone asks.

The sections below quote the live steps for each move.

1. Set the Action Button to open Grok Bot

Apple's guide is for supported iPhones, where the Action button replaces the Ring/Silent switch. Assign the action named Shortcut, which is the one Apple describes as opening an app. Then select the option that opens the Grok Bot app. Apple's page does not list Grok Bot by name, and it does not say this starts a voice chat.

On supported models, iPhone has an Action button in place of the Ring/Silent switch. You can choose which function you want the Action button to perform when you press it.

To perform the action assigned to the Action button, press and hold the Action button.

Use and customize the Action button on iPhone

To assign it:

Go to the Settings app on your iPhone.

Tap Action Button.

To choose an action (like Silent Mode), swipe to the action you want to use—its name appears below the dots.

If there are additional options for the selected action, the Menu button appears below the action; tap it to see the list of options.

For the Controls, Shortcut, and Accessibility actions, you need to tap the button below the action and select a specific option—otherwise the Action button does nothing.

Shortcut: Open an app or run your favorite shortcut.

Use and customize the Action button on iPhone. On the live page, “the Menu button” is the alt text of the icon inside that sentence.

Swipe until the name below the dots is Shortcut. Tap the button below that action and select the option that opens the Grok Bot app. Apple says that without a specific option, the Action button does nothing.

Shortcut, in this guide, is the name of an Action Button action. It can open an app, or it can run a shortcut you already have. This page does not add a step inside the Shortcuts app. See the device note below.

2. Open the Bot, then Start voice chat

Press and hold the Action Button. Grok Bot opens. The call has not started. Open the Bot, then use the waveform button.

Open the chat with the Bot.

Leave the message box empty.

Choose Start voice chat. It is the waveform button in the message box.

Allow microphone access if your computer or phone asks.

The call shows Connecting… on desktop or Calling… on the phone, then the Bot starts talking.

Start voice chat shows only when the message box is empty.

Voice chat with a Bot, “How do I start a voice chat?”

On the phone, that waveform control is a tap. The help page's verb is “Choose.” The phone shows Calling… when the call is actually starting.

3. If Start voice chat is missing

An empty message box is the first check. If the box is empty and the waveform button is still absent, update Grok Bot. The voice-chat page links “How do I update Grok Bot?” for that.

Start voice chat shows only when the message box is empty. If the box is empty and you still don't see it, update Grok Bot. See How do I update Grok Bot?

Voice chat with a Bot

The desktop app checks for updates on its own. When one is ready, the account menu shows New update available. Choose Install, then Restart to update. Your Bots keep working in the cloud while the app restarts.

To check yourself, open Settings, go to Updates, and choose Check for Updates. If an update is ready, choose Restart to Update. Automatic Updates installs updates while you're away.

Phone updates come from the App Store or Google Play. Product changes are listed on the changelog.

Grok Bot How Tos, “How do I update Grok Bot?”

On an iPhone, the update comes from the App Store.

Desktop: Cmd+D is voice typing

Voice chat on desktop uses the same waveform button, Start voice chat. Cmd+D and Ctrl+D do something else. They start voice typing, not a voice call.

Voice typing turns your speech into text in the message box. You read it, edit it, and send it like any other message. The Bot replies in text.

On desktop, choose Start voice input in the message box. You can also press Cmd+D on Mac or Ctrl+D on Windows and Linux, or hold the keys while you talk.

On the phone, tap Start dictation.

A voice chat is a live conversation. The Bot answers out loud and keeps listening until you hang up.

On the phone, stop dictation before you start a voice chat.

Voice chat with a Bot, “How is a voice chat different from voice typing?”

The live page shows Cmd+D in the Mac slot of that first key mark, and Ctrl+D for Windows and Linux. Pressing those keys chooses Start voice input. It does not choose Start voice chat.

Limits

Only one voice chat runs at a time. If you start another one, Grok Bot asks End the current voice chat? Choose End and Chat to switch.

Voice chat with a Bot, “What can I do during a voice chat?”

No. Voice chat works with one Bot at a time. Open that Bot's own chat to start a call.

Voice chat isn't available with a teammate's Team Bot.

What the mobile page says

The Grok Bot mobile help page tells you to install the app and sign in. Its article text does not mention the Action Button, the Shortcuts app, a widget, or starting a voice chat. Voice chat stays on the voice-chat page quoted above.

Use Grok Bot on your phone with the same account and cloud computer as desktop. Grok Bot is available on iOS and Android.

Install the current Grok Bot mobile app from the App Store on iOS or Google Play on Android.

Sign in on mobile with the same Cursor account you use on desktop or web.
