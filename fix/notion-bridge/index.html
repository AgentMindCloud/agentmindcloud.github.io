Handoff guide

Grok Bot and Claude, on one private Notion board

The docs checked on 9 October 2026 describe no direct link between a Grok Bot and a Claude chat session. A shared Notion database is the path those docs support: each product documents its own Notion connection, and the board is the place they both can be aimed at.

What the docs actually say

Cursor’s Grok Bot help lists plugins and routines. The plugin page names Notion. The routines page tells you to ask a Bot, in chat, for a schedule such as every weekday at a stated time. Neither page mentions Claude. Claude’s connector directory lists a Notion connector made by Notion. That connector page does not mention Grok Bot. Nothing on those pages describes a pipe from a Grok Bot into a Claude chat session, or the other way around.

Connect Gmail, Notion, Slack, and other services so agents can use them in chat.

Plugins let agents talk to external services. Plugin connections belong to the same account you used to sign in to Grok Bot.

A plugin uses the account you authorize. It can do only what that account can already do in that service. It cannot raise your access, and it cannot change sharing.

Some other plugins, like Notion, can connect a second account.

A routine tells one Bot when to run a workflow. It can run on a schedule, or when something happens, such as a Slack message, a GitHub, Linear, Sentry, or PagerDuty event, an email, or a webhook call. Routines run in the cloud while your laptop is closed.

Ask the Bot in chat. Say what it should do and when. For example: “Every weekday at 9:00 AM, summarize new support tickets in this chat.” The Bot creates the routine, and it appears in the Bot’s routines.

Schedules use the time zone in Settings, under Bot, labeled Timezone.

Ask for a schedule in plain words, like “every weekday at 8:00 AM” or “every 2 hours”. Then open the routine and check When to run.

Handoff board

Build this as a private database in your own Notion workspace. Five properties. Status is a Select, with the options Todo, Claimed, and Done. Owner is a separate Select, with the options Grok Bot and Claude.

Copy-paste property table. Types and options are the ones to create.
Property Type Options or behavior
Title Title The first column. It holds the name of the database page.
Status Select Todo, Claimed, Done
Owner Select Grok Bot, Claude
Notes Text The result of the work, written by whichever owner ran the row.
Updated Last edited time Notion fills this when the row changes. You do not type it.

Why Status is a Select

Notion also has a Status property. Its help says the three main categories stay fixed, and custom tags sit underneath them. Todo, Claimed, and Done are not those three categories, so this template uses Select, which is the type Notion describes as one option from a list of tags you add yourself.

Select. Choose one option from a list of tags. Useful for categorization.

Status. Track this item’s progress using status tags categorized by To-do, In Progress, or Complete.

Text. Add text that can be formatted. Great for summaries, notes, and descriptions!

Last edited time. Records the timestamp of an item's last edit. Auto-updated and not editable.

Set up the database

Do this in a private page. Do not publish it, and do not turn on access for anyone on the web.

  1. Create a new page and, under Get started with, select •••, then Table. On a page you already have open, the slash command /database is the other way Notion documents. Create a database says: “The first column is where you enter the name of your database pages. Each column in a Notion table corresponds to a property that gives your item context.”
  2. Name the database Handoff board. Rename the first column to Title. Database properties says you can click into a property and edit the property’s name.
  3. Add a property named Status. Choose Select. Add the options Todo, Claimed, and Done. Create a database says to click the property name, choose Edit property, and select Add an option. Database properties says that for a Select “you’ll be prompted to add tags by typing what you want and pressing enter after each.”
  4. Add a property named Owner. Choose Select. Add the options Grok Bot and Claude, the same way.
  5. Add a property named Notes. Choose Text.
  6. Add a property named Updated. Choose Last edited time. Database properties says values automatically appear for Last edited time.
  7. Leave a new row at Status Todo, and set Owner to Grok Bot or Claude depending on who should do that row. Put the task in Title. Leave Notes empty until that side runs.

Keep the board private. Sharing and permissions says: “Select Share at the top of any page to: Invite someone to the page.” It also says: “Open the Publish tab to share a page to the web.” And: “Anyone on the web with link: This means that anyone who has the link to your page can access it, even if they aren’t part of your workspace or aren’t a Notion user.” Publish a website with Notion Sites says: “To ensure your page’s contents aren’t shared publicly, turn this setting off by clicking Share at the top of your Notion page, opening the dropdown next to Anyone on the web with link, and clicking Remove.” Do not publish this database. Do not set Anyone on the web with link.

Invite only the Notion account you will connect to Grok Bot, and the Notion account you will connect to Claude. Sharing and permissions says people with Can edit content “can create and edit pages within the database, and edit property values,” and that they “will not be able to change the structure of the database and its properties.” Add the five properties yourself before you rely on an account that only has Can edit content. Connect plugins says a plugin cannot change sharing, so the Notion account you authorize has to already be allowed to edit the rows.

Grok Bot routine

Connect Notion on the same Cursor account that owns the Bot, then ask that Bot for the routine in chat. The schedule below is weekdays at 9:00 AM, which is the shape of the example on the routines page (“Every weekday at 9:00 AM, summarize new support tickets in this chat.”). After the Bot saves it, open the routine and read When to run. Schedules use the time zone in Settings, under Bot, labeled Timezone.

  1. In Grok Bot, select Plugins on the sidebar, or follow an in-chat Connect card. Browse or search for Notion, then add it. When Grok Bot asks you to Authorize or Authenticate, finish the provider login in your browser. Confirm the plugin appears under Installed. Those steps are the numbered list under “How do I add a plugin?” on Connect plugins.
  2. Added means the plugin is installed, not that you are signed in. If it shows Needs auth or Disconnected, open it and choose Authorize. That sentence is on the same page.
  3. Ask the Bot in chat. Paste the instruction below, including the weekday time. Routines says: “Say what it should do and when.” The Bot creates the routine.
  4. Open the routine. Instruction is what the Bot does on each run. When to run lists the schedule. If the words do not match weekdays at 9:00 AM in the time zone you expect, choose Edit and tell the Bot what to fix. A new schedule waits for its next time.

Paste this as the routine. It is intent only.

Every weekday at 9:00 AM, use the Notion account already connected to this Bot and open the private database named Handoff board. Work only on rows whose Owner is Grok Bot and whose Status is Todo or Claimed. On each such row, set Status to Claimed, do the work named in Title, write the result in Notes, and set Status to Done. If no such row exists, leave the database unchanged and say so in this chat. Leave every row whose Owner is Claude as you found it. Do not change sharing, and do not publish the database.

Claude instruction

Claude’s getting-started page describes connectors inside a conversation. It does not describe a weekday schedule for a connector. Use the instruction when you want Claude’s rows handled. The Owner filter is what keeps Claude off the Grok Bot rows.

  1. Open Customize, then Connectors. Select Discover, enter Notion in Search connectors, and open the Notion connector. Select Connect to Claude and finish sign-in. Getting started says: “When sign-in finishes and you’re back on the Connectors page, the connector is listed under Your connectors with the status Connected.” Those controls are on Get started with connectors. The listing itself is the Notion connector page, which says it is made by Notion and that sign-in is required.
  2. In a chat, select + in the message box and select Connectors. Turn the Notion connector on for that conversation. Getting started says the toggle controls whether Claude can use the connector in this conversation.
  3. Send the instruction below. Getting started says to send a message that needs the service, and that Claude can ask for approval before it uses one of the connector’s tools. Select Allow once, or Always allow, only for an action you intend on this private database.

Paste this into the Claude chat. It is intent only.

Use the connected Notion account and open the private database named Handoff board. Work only on rows whose Owner is Claude and whose Status is Todo or Claimed. On each such row, set Status to Claimed, do the work named in Title, write the result in Notes, and set Status to Done. If no such row exists, leave the database unchanged and say so in this chat. Leave every row whose Owner is Grok Bot as you found it. Do not change sharing, and do not publish the database.
